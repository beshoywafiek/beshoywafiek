# beshoywafiek.github.io

Bilingual (Arabic / English) portfolio. Static HTML generated by a Python
script — no framework, no bundler, nothing to install at runtime.

**The published site lives at the repository root.** GitHub Pages serves it
from there, so `index.html`, `css/`, `js/`, `work/`, `services/` and `images/`
must stay where they are. They are generated — edit `_source/`, not them.

## Working on it

```bash
npm install                  # playwright, for the tests only
npm run build                # regenerate the site from _source/
npm run serve                # serve on :8099 (the tests need this running)
npm test                     # 15 gates — all must pass before pushing
```

- **`_source/content.py`** — all the copy and settings
- **`_source/meta.py`** — project names, order, per-project story
- **`_source/icons.py`** — the icon set
- **`_source/src/`** — the authored CSS and JS
- **`_source/tests/`** — the gates

`CLAUDE.md` holds the rules this project learned the hard way. Read it before
touching the hero, anything RTL, or anything animated.

`HOW-TO-EDIT.md` is the owner's guide, in Arabic.
